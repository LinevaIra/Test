# 001 — Список чатов и пространств

Актуальные требования первого экрана: [002-space-main.md](002-space-main.md).
Этот документ сохранён как описание исходного прототипа; при противоречиях
для дальнейшей разработки используйте новую редакцию.

Статус: описание существующего прототипа; функциональная приёмка не выполнена.
Дата: 2026-10-07.

## Цель и источники

Показать переписки и организационные пространства на одном стартовом экране.
Источник: запрос пользователя на первый экран и
[контекст продукта](../docs/product-context.md).
Сохранённый чат «Пространство» не прочитан и не является источником
дополнительных требований этой спецификации.

## Требования пользователя

- Первый экран приложения — список чатов в стиле Telegram.
- В списке присутствуют пространства: группировки чатов вокруг организационного контекста.
- Приложение состоит из четырёх экранов и не содержит бэкенд-логики.
  Эта спецификация описывает только первый экран.

## Решения текущего прототипа

- SwiftUI, iOS 17+, русскоязычный интерфейс, демонстрационные данные в памяти.
- У чатов показаны аватар, название, последнее сообщение, время и непрочитанное.
- Пространства отличаются карточкой, квадратной иконкой и меткой «Пространство».
  Показаны число и названия вложенных чатов, последнее сообщение и общий счётчик.
- Поиск, фильтры и действия работают локально; сетевых операций нет.
- Названия, участники, сообщения и счётчики — фикстуры, а не реальные данные.
  Общий счётчик пространства задан в фикстуре; вычисление из вложенных сообщений
  не входит в текущий прототип.

## Границы

Входит: список, поиск, фильтры, создание локального чата, закрепление,
отметка о прочтении, переключение состояния «Без звука», восстановление списка.

За пределами: переписка, экран содержимого пространства, авторизация, сервер,
реальные уведомления, постоянное хранение и вычисление агрегатов.
Нажатие строки пока не открывает другой экран.

## Сценарии и критерии приёмки

| ID | Условие и действие | Наблюдаемый результат |
| --- | --- | --- |
| AC-01 | Первый запуск | Заголовок «Чаты», поиск, три фильтра; восемь элементов, из них два пространства |
| AC-02 | Просмотр «Студия Север» | Метка «Пространство», четыре вложенных чата, их названия, последнее сообщение и счётчик 12 |
| AC-03 | Поиск `Разработка` в фильтре «Все» | Найдена «Студия Север» по названию вложенного чата |
| AC-04 | Поиск имени или текста сообщения | Результаты соответствуют запросу без учёта регистра; поиск не отменяет текущий фильтр |
| AC-05 | Выбор «Пространства» | Видны только «Студия Север» и «Дом на Лесной» |
| AC-06 | Выбор «Непрочитанные» на исходных данных | Видны пять элементов; число на фильтре — 5, это число элементов, а не сообщений |
| AC-07 | Поиск заведомо отсутствующего текста | Показано «Чаты не найдены» и подсказка изменить запрос или фильтр |
| AC-08 | Свайп влево → «Прочитано» | Счётчик элемента исчезает; элемент пропадает из фильтра непрочитанных; число на фильтре уменьшается |
| AC-09 | Свайп влево → «Без звука», затем «Включить звук» | Метка и цвет счётчика отражают локальное состояние; реальные уведомления не изменяются |
| AC-10 | Свайп вправо → «Закрепить», затем «Открепить» | Закреплённые элементы идут первыми; внутри групп порядок остаётся прежним |
| AC-11 | Новый чат с названием из пробелов | Кнопка «Создать» недоступна; пустой чат не добавляется |
| AC-12 | Новый чат с непустым названием | Пробелы по краям убраны; чат появляется перед незакреплёнными, с текстом «Пока нет сообщений»; поиск очищен и выбран фильтр «Все» |
| AC-13 | Отмена создания | Новый элемент не появляется |
| AC-14 | «Править» → «Прочитать всё» | Все счётчики обнулены; фильтр непрочитанных пуст |
| AC-15 | «Править» → «Восстановить список» или завершение и повторный запуск | Восстановлены исходные элементы и их состояния; пользовательские изменения не сохраняются |
| AC-16 | Светлая и тёмная темы, увеличенный системный размер текста, VoiceOver | Основные действия доступны, названия и счётчики читаемы; оформление не скрывает элементы управления |
