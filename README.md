# spaces-ios

Стартовое приложение для iPhone и iPad на SwiftUI (iOS 17+).

Контекст, требования и ссылка на исходный чат: [docs/product-context.md](docs/product-context.md).

Разработка по спецификациям (SDD): [процесс](specs/README.md) и
[спецификация первого экрана](specs/002-space-main.md).
Главная страница реализована по новой редакции. Приёмка интерфейса в симуляторе ещё не выполнена.
Созданы спецификации [главной пространства](specs/space-space.md) и
[активностей](specs/space-activity.md); их содержимое пока не реализовано.

## Запуск

1. На macOS с Xcode 15 или новее откройте `spaces-ios/Spaces.xcodeproj`.
2. Выберите схему `Spaces` и установленный симулятор iPhone или iPad.
3. Запустите приложение: **Product → Run** (`⌘R`).

Для запуска на физическом устройстве выберите свою команду в **Signing & Capabilities**
и при необходимости измените Bundle Identifier `com.example.spaces`.
Внешние зависимости, сервер и секреты не требуются.

## Что есть в проекте

- Главная в стиле Telegram: компактный светлый список с зелёными акцентами.
- «Проект Сбер.продукт» — пространство с буквенным аватаром «СП», мягким
  скруглением, меткой типа, контекстом «Чат · Почта · ВКС» и общим счётчиком.
- Под пространством три вложенные строки: канал #general и чаты Разработка/QA.
  Они видны при включённых уведомлениях и наличии непрочитанного, с отступом
  и зелёными счётчиками 3/5/4. Все аватары — буквы, внешних загрузок нет.
- Нажатие на пространство открывает его страницу; на дочерний чат/канал —
  напрямую выбранный диалог. Это отдельные пустые экраны с заголовком
  «Проект Сбер.продукт»; их содержимое будет задано отдельными спецификациями.
- Кнопка активностей доступна в шапках главной, пространства и диалога:
  зелёные речевые плашки с тремя точками, без видимой подписи. Ведёт к одному
  пустому экрану активностей с возвратом к источнику; лента пока не реализована.
- В модели сохранены публичный #general, разделы Чат/Почта/ВКС и приватные
  сущности РО, Разработка, QA; полное дерево не раскрывается на главной.
- Поиск и фильтры Все/Непрочитанные/Пространства сохраняют родительский контекст.
  Индикатор непрочитанного считает верхний уровень без дублирования детей.
- Локальные read/mute скрывают дочерние строки. Mute сохраняет непрочитанное;
  read уменьшает сумму родителя. Pin перемещает блок пространства целиком.
- Создание чата, прочтение всех и восстановление списка; данные в памяти.
  Переход в диалог сам по себе не отмечает сообщения прочитанными.
- iPhone и iPad: один список, ширина до 860 pt, обе ориентации, узкие окна,
  Dynamic Type и действия через свайп, контекстное меню и VoiceOver.
- Общая схема Xcode для запуска и сборки; сервер и авторизация отсутствуют.

## Проверка сборки

На macOS выполните из корня репозитория:

```sh
xcodebuild -project spaces-ios/Spaces.xcodeproj -scheme Spaces \
  -sdk iphonesimulator -configuration Debug \
  -derivedDataPath /tmp/spaces-ios-derived-data CODE_SIGNING_ALLOWED=NO build
```

В облачной Linux-среде нет Xcode и iOS SDK, поэтому сборка приложения
и проверка в симуляторе выполняются на macOS.

## Проверка модели

Модель `Spaces/ChatListModel.swift` также включена в локальный Swift Package
без внешних зависимостей. Пакет проверяет только модель; SwiftUI-вёрстка
собирается через `Spaces.xcodeproj`.

```sh
swift test --package-path spaces-ios
```

18 тестов прошли в Linux с официальным Swift 5.10.1: структура и иерархия,
аббревиатуры, поиск/фильтры, счётчики, read/mute/pin, создание/восстановление,
точные маршруты пространства/диалога и возврат из активностей без дублей.
Проверка синтаксиса всех исходников Swift также прошла; она не заменяет
проверку типов SwiftUI и сборку iOS-приложения.

Для визуальной приёмки выберите в Xcode схему `Spaces` и проверьте iPhone
и iPad в двух ориентациях, узкое окно iPad и крупный системный шрифт.
В `ContentView.swift` добавлены пять соответствующих Canvas previews.
