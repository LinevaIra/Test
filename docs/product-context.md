# Контекст проекта spaces-ios

## Источники

- Требования пользователя из текущего чата разработки.
- Сохранённый чат ChatGPT «Пространство»: https://chatgpt.com/share/6ac513f8-f4fc-83ed-a745-eba0fcf6350f

**Статус импорта сохранённого чата:** не выполнен. При попытке чтения
ссылки 6 октября 2026 года получен HTTP 403 Forbidden. Содержание этого
чата не прочитано; приведённые ниже требования получены только из текущего
диалога. Для дополнения контекста нужен текст или экспорт сохранённого чата.

## Подтверждённые требования пользователя

- Название проекта: `spaces-ios`.
- Простейшее приложение для iOS из четырёх экранов, без бэкенд-логики.
- Первый экран — список чатов в стиле Telegram.
- В одном списке с чатами присутствует сущность «Пространство».
- Пространство — группировка чатов вокруг организационного контекста.
- Для одного из следующих экранов задано назначение «Активности»;
  доступ к нему сквозной из всех экранов.
- Экран пространства и экран диалога внутри пространства — два разных экрана;
  спецификация пространства теперь создана, диалог ещё ожидает своей.

### История: исходная редакция первого экрана (2026-10-07)

Целевые требования сохранены в [specs/002-space-main.md](../specs/002-space-main.md):
максимальное сходство с Telegram и скриншотами библиотеки «Пространства»,
светлая тема с зелёными элементами, явная строка пространства с квадратным
аватаром. Пространство связано с продуктом «Проект Эфир», публичным каналом
важных объявлений (аналог #general), разделами «Чат», «Почта», «ВКС»
и приватными каналами для РО, разработки и QA внутри разделов.
Пользователь прикрепил три скриншота, они просмотрены. На них показаны
состояния экрана пространства; для первого экрана берётся только стилистика
(цвета, типографика, аватары, разделители и счётчики). Структура пространства,
раскрываемые разделы, архив и его меню в список чатов не переносятся.
По следующему запросу пользователя новая редакция реализована в коде.
Первый экран остаётся общим списком чатов; вёрстка адаптируется для iPhone
и iPad, без добавления второго экрана.

### История: компактность и корпоративные аватары (2026-10-07)

Пользователь попросил мягче скруглить прямоугольный аватар пространства,
добавить в шапку «Активности» рядом с созданием чата и сделать список компактнее.
В спецификации предложены аватары 48 pt, непрерывное скругление пространства
около 14 pt и вертикальные отступы строки 8 pt. По последнему запросу
эти параметры внесены в код. Кнопка активностей отображается только спокойной иконкой
списка событий, без видимой подписи; для VoiceOver сохраняется название
«Активности». Иконка — `list.bullet.rectangle`; молния исключена как слишком
агрессивная, колокольчик зарезервирован для уведомлений и для этой кнопки
не используется. Кнопка открывает пока пустой каркас отдельной страницы
с заголовком и возвратом; лента будет описана в собственной спецификации.
Дополнительно запрошены корпоративные аватары пространства и части чатов.
В спецификации предложены единая зелёная графика для «Проект Эфир»,
«Команды продукта» и «Обсуждения релиза», с разными символами и сохранением
прямоугольной маски пространства и круглых масок чатов. Созданы и добавлены
три локальных векторных PDF-аватара, с резервным отображением при отсутствии ресурса.

### Новое уточнение иконки активностей (2026-10-07)

Пользователь предоставил референс с двумя перекрывающимися речевыми плашками,
тремя точками и бейджем «1». Целевой рисунок кнопки изменён на похожие
плашки с тремя точками, адаптированные к плоской зелёной стилистике шапки.
Подпись остаётся невидимой, счётчик не добавляется без отдельного требования.
По текущему запросу в коде добавлена векторная SwiftUI-иконка двух плашек
с тремя точками вместо `list.bullet.rectangle`.

### Последние уточнения названия и списка (2026-10-07)

Целевое название пространства теперь **«Проект Сбер.продукт»**, аббревиатура
**«СП»**. На всех аватарах — только текстовые аббревиатуры; прежнее требование
корпоративных изображений заменено. Скруглённый прямоугольник пространства,
круги чатов, компактная светлая вёрстка и зелёные акценты сохраняются.

На главной под пространством добавлены три иерархически привязанные сущности.
Условие показа — включённые уведомления и непрочитанное; индикаторы зелёные.
Выбранная демонстрационная тройка: публичный канал #general (3), приватные
чаты «Разработка» (5) и «QA» (4) из раздела «Чат». Названия и числа — решение
прототипа. Связь с родителем обозначена отступом; mute или прочтение скрывают
дочернюю строку. Полное дерево разделов на главной не раскрывается.

Эти изменения по
[спецификации главной](../specs/002-space-main.md) внесены в код
после запроса пользователя на реализацию; прежние PDF-аватары удалены.

### Переходы из главной и сквозные активности (2026-10-07)

Нажатие на строку пространства открывает экран пространства. Нажатие
на вложенный незамьюченный чат/канал с активным непрочитанным уведомлением
ведёт непосредственно в диалог выбранной сущности внутри пространства,
без промежуточного открытия экрана пространства. Это два разных экрана,
для которых пользователь напишет отдельные спецификации.

На главной заголовок «Чаты»; на экране пространства и в его диалоге —
название пространства «Проект Сбер.продукт». Доступ к «Активностям» сквозной:
одна и та же кнопка по R4 доступна из всех экранов и ведёт к единому экрану
активностей. Его содержимое и собственная шапка ожидают отдельной спецификации.
Для возврата принято сохранение экрана-источника и контекста; переход в диалог
сам по себе не задаёт момент автоматического прочтения.

В спецификации главной записан только этот контракт навигации и шапки.
По запросу на реализацию в коде созданы разные маршруты и отдельные
пустые экраны назначения с общей шапкой. Их содержимое остаётся для
будущих спецификаций пользователя.

### Главная пространства и страница активностей (2026-10-07)

Созданы две спецификации без изменения приложения:
[space-space.md](../specs/space-space.md) и
[space-activity.md](../specs/space-activity.md).

Внутри пространства верхняя область содержит разделы, чаты и каналы, включая
muted и прочитанные, с примерами упоминаний. Пользователь уточнил: «размечена»
означает включённые уведомления, отдельные метки не требуются. Шапка особенная,
с мягким зелёным акцентом и явным контекстом пространства. Нижняя область —
пять последних личных диалогов из общей модели, независимо от пространства.

Активности доступны из шапок главной, пространства, диалога и треда. Четыре
независимо раскрывающихся раздела: подписанные обсуждения-треды, сообщения
с упоминанием меня, последние личные диалоги, события подписанных ресурсов
(заметки, текущие/недавние хаддлы, канвасы). Точка входа не фильтрует общую ленту.
Пять личных диалогов для активностей и семь суток для недавних ресурсов —
явные решения прототипа. Содержимое диалога и ресурсных редакторов ещё не задано.

### Реализация главной пространства (2026-10-07)

По запросу пользователя реализован `space-space`: светлая зелёная шапка,
общий #general и раскрывающиеся Чат/Почта/ВКС с десятью сущностями.
Прочитанные и muted строки остаются внутри пространства; unread и mentions
разделов агрегируются, явное прочтение снимает оба состояния, mute их сохраняет.
Нижняя область — пять последних личных диалогов из шести общих фикстур,
с сортировкой по датам сообщений и устойчивому ID при равенстве.

Новые личные примеры Ирина/Сергей участвуют в общем источнике данных, но
не добавляются к начальной выборке из семи обычных чатов на главной.
Состояние, read/mute и идентификаторы общие. Отдельный личный маршрут
не хранит идентификатор пространства. Его содержимое пока пустое;
шапка показывает собеседника до будущей спецификации диалога.

В обычном окне области имеют независимую прокрутку; в низком окне и при
accessibility-шрифтах используется один список. Состояния разделов и видимые
строки сохраняются над экраном. Фактическое восстановление прокрутки в iOS
ещё требует визуальной проверки. Активности остаются пустым экраном.

## Текущее состояние реализации

- SwiftUI, iOS 17+, общая схема Xcode `Spaces`, приложение для iPhone и iPad.
- Главная: семь обычных чатов, «Проект Сбер.продукт» и три дочерние строки
  #general, Разработка, QA. Дочерние строки сдвинуты на 20 pt и имеют зелёные
  счётчики 3/5/4; показаны только при включённых уведомлениях и непрочитанном.
- Все аватары буквенные: «СП» у пространства, остальные по таблице спецификации.
  Размер 48 pt, continuous-скругление пространства 14 pt; чаты круглые.
  Вертикальные отступы 8 pt; интерфейс светлый с зелёными акцентами.
- Общий счётчик пространства — сумма непрочитанного детей. Прочтение скрывает
  дочернюю строку и уменьшает сумму, mute скрывает её без обнуления.
- Поиск учитывает родительский контекст; фильтры сохраняют иерархию. Индикатор
  непрочитанного считает верхний уровень без повторного учёта дочерних строк.
- Нажатие на пространство открывает его главную с рабочей и личной областями;
  на дочерний чат/канал — сразу пустую страницу выбранного диалога.
  На обеих страницах заголовок «Проект Сбер.продукт» и кнопка активностей.
- Общая иконка активностей — две контурные речевые плашки с тремя точками,
  без подписи/бейджа. Все точки входа открывают один пустой экран активностей;
  системный возврат возвращает к экрану-источнику.
- Пространство реализовано; активности пока описаны без содержимого в коде.
  Рабочие/личные диалоги и треды ожидают спецификации. Переход в диалог
  не отмечает сообщения прочитанными.
- На широком iPad страница центрирована, не шире 860 pt; на iPhone/узком iPad
  занимает доступную ширину. Сохранены адаптация к Dynamic Type и действия VoiceOver.
- Данные и навигация в памяти; нет сервера, авторизации, push или сохранения.
  Создание, pin, mute/read, прочтение всех и восстановление списка локальные.

Обычные чаты, сообщения, время и числа — демонстрационные данные.
Названия продукта, разделов и ролей заданы пользователем; состав трёх
видимых дочерних строк — явно записанное решение для прототипа.

## Проверка

32 теста модели и маршрутов прошли на Swift 5.10.1 в официальном Linux-контейнере.
Проверены иерархия, аббревиатуры, поиск, фильтры, агрегирование непрочитанного,
read/mute, целостность блока при pin, создание/восстановление, точные маршруты
и возврат из активностей без дублирования. Дополнительно проверены полная
структура пространства, mentions, сворачивание, общая личная пятёрка, даты,
новое сообщение и пустые выборки. Синтаксис Swift и структура Xcode
проверены. Проверка типов SwiftUI, сборка, визуальное сравнение, жесты,
сохранение прокрутки и VoiceOver требуют macOS с Xcode и пока не выполнены.
Команда сборки и инструкции запуска находятся в [README](../README.md).
